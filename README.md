# Summary

UD_NorthernLuri-KHS is a treebank of the Khoranabadi variety of Northern Luri, annotated according to the Universal Dependencies framework.

# Introduction

UD_NorthernLuri-KHS is a manually annotated treebank for the Khoranabadi dialect of Northern Luri, an Iranian language spoken in the Khorramabad region of western Iran. The data consists of 80 sentences drawn from natural spoken and/or written texts in Khoranabadi Luri. Each sentence in the treebank includes the original Luri text in romanized transcription, a corresponding Persian equivalent (`# original_text`), and an English translation (`# translation`).

The data sources are from various written prose and oral narratives.

The annotation follows the Universal Dependencies guidelines and covers tokenization, lemmatization, morphological features (including number, person, tense, aspect, mood, voice, polarity, and pronoun type), part-of-speech tags (UPOS), and syntactic dependency relations. All annotation was performed fully manually by human annotators. XPOS tags are not provided.

The current release consists of a single dataset of 80 sentences (654 tokens) and has not yet been divided into training, development, and test splits. A formal split will be introduced in a future release as the treebank grows.

The treebank consists of isolated sentences drawn from natural source texts and does not include full documents. All sentences share the same dialect source. The genre is best classified as spoken, reflecting the colloquial nature of the Khoranabadi dialect data. Sentences are identified by sequential numeric IDs (`# sent_id = N`).
